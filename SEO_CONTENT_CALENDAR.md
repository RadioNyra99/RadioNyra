## Publishing checklist

- Assign one primary query to each article and link it to a relevant, existing Radio Nyra page.
- Write a unique title, description, and one clear H1; use descriptive H2 headings.
- Include useful original detail, named sources for event/news facts, publication date, and an editor.
- Add meaningful image alt text; use an empty alt only for decorative images.
- Add an unobtrusive listen/watch action where it fits the article.
- Do not publish keyword-density targets, unsupported rankings, demographic estimates, or audience statistics as facts.
- Review outdated dates and links before each event roundup; remove or update expired listings.
